# LazyIndie

LazyIndie is a modern, feature-rich music collaboration and artist discovery platform built with React and Vite. It enables artists, producers, and fans to connect, collaborate, and explore music in a visually engaging and interactive environment.

## Features

- 🎵 Artist discovery and detailed artist catalog pages
- 🤝 Collaboration and community sections
- 💬 AI-powered chat for artist matching
- 🛒 Cart and wallet integration (Solana wallet support)
- 📱 Responsive, animated UI with Framer Motion
- 🔍 Search and filter for projects and opportunities
- 🖼️ Rich media support (images, GIFs, and more)
- 📝 Reviews, ratings, and social media integration
- 🛠️ Built with React, Vite, Tailwind CSS, and modern libraries

## Getting Started

### Prerequisites
- Node.js (v16+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
https://github.com/yourusername/lazyindie.git
cd lazyindie

# Install dependencies
npm install
# or
yarn install
```

### Running the App

```bash
npm run dev
# or
yarn dev
```

The app will be available at [http://localhost:5173](http://localhost:5173) by default.

## Project Structure

- `src/components/` — Main React components (Home, End, WalletConnectPage, etc.)
- `src/catalog/` — Artist catalog and profile pages
- `src/launch_pages/` — Animated onboarding/launch screens
- `src/assets/` — Images, GIFs, and static assets
- `src/ai_section_dummy_matches/` — AI chat and artist matching logic

## Key Technologies
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide Icons](https://lucide.dev/)
- [Solana Wallet Adapter](https://github.com/solana-labs/wallet-adapter)

## Customization
- Update artist data, images, and catalog in `src/catalog/` and `src/assets/`.
- Adjust navigation and routes in `src/App.jsx` and `src/components/`.
- Modify styles using Tailwind CSS classes or custom CSS.
